# cant-stop

Can't Stop 掷骰爬塔游戏的终端还原：4 骰分两对爬列，3 个进行中标记，爆掉作废、停手存档，先完成 3 列者胜。

## 玩法

- 每轮掷 4 颗骰子，分成两对（程序自动枚举 3 种分法取最优放置）。
- 每对的和对应一列（2–12），在该列放置或推进你的标记。
- 同时最多 3 个进行中标记；掷出的两对都无处可放即**爆掉**，本轮进度作废。
- 主动停手则进度**存档**；一轮内爬满一列会立刻释放标记槽位。
- 列高度（标准规则）：2:3 / 3:5 / 4:7 / 5:9 / 6:11 / 7:13 / 8:11 / 9:9 / 10:7 / 11:5 / 12:3。

## 用法

```bash
python -m cant_stop auto --games 10 --seed 42   # AI 自动对战演示
python -m cant_stop auto --games 5 --verbose     # 看逐轮过程
python -m cant_stop play                         # 人机对战（你是玩家0）
```

## AI 说明

- 玩家0 用**贪心停手**策略：接近完成、本轮完成一列、或 runner 满 3 且推进 ≥4 格时停手。
- 玩家1 用**保守停手**策略：推进 ≥3 格就停手。
- 放置阶段双方都用最优分对枚举（3 种分法 × 2 种顺序取放置数最多者）。

## 真实验证记录

- `py_compile`：通过。
- 单元测试（`/tmp/test_cant_stop.py`，12 项）：分对去重（`[1,1,6,6]`→`[(2,12),(7,7)]`）、爆掉判定、完成列释放槽位并存档、满 3 列判胜、非法走法拒绝、同种子可复现、AI 停手策略触发条件——全部通过。
- `--auto --games 10 --seed 42`：10 局全部自然终局，玩家0（贪心）胜 10，玩家1（保守）胜 0；`--games 20 --seed 7`：16:4。对照实验：同策略对局（贪心vs贪心、保守vs保守）胜负接近 5:5，说明规则对称无先手 bug，贪心策略本身更强（敢于推进）。
- 爆掉路径专项验证：永不停手 AI 20 轮全部爆掉（20/20），且爆掉后玩家永久进度未被污染；正常 AI 因早停手（推进 3–4 格即存档）爆掉罕见，属策略行为而非 bug。
- 非 tty 下 `play`：中文提示并以 exit 2 退出。
- 无 TODO/FIXME 占位；`__pycache__` 已清理。

## 已知局限（诚实版）

- AI 只是固定阈值贪心，不做爆掉概率的精确计算（如 7 列 13 格的长征风险），懂概率的人类通常能赢。
- 人机对战中放置由程序自动取最优，玩家只做"继续/停手"决策（简化交互）。
- 文本界面，无图形/动画/存档/悔棋/网络对战；Python 3.10+，纯标准库。
